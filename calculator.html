Калькулятор ремонтов

Costul fiecărei lucrări se împarte între apartamente proporțional cu suprafața. O lucrare pentru o singură scară se împarte doar între apartamentele acelei scări.

Стоимость каждой работы делится между квартирами пропорционально площади. Работа для одного подъезда делится только между квартирами этого подъезда.

Suprafețele apartamentelor sunt date de exemplu Площади квартир — примерные данные

Totalul (12.745 m², 220 ap.) este real, dar repartizarea pe apartamente este orientativă până la încărcarea registrului real.

Общая площадь (12 745 м², 220 кв.) реальная, но распределение по квартирам ориентировочное до загрузки реального реестра.
